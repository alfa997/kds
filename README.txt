ECOLOKA CHANGE WEBSITE
1. Ekstrak folder ecoloka-change.
2. Buka index.html di browser (Chrome/Edge).
3. File dipisah: index.html, style.css, script.js.
4. Tidak membutuhkan instalasi atau database.
5. Untuk mengubah materi, edit bagian content di script.js.
6. Untuk mengubah warna, edit variabel di bagian :root pada style.css.

Catatan keselamatan:
Bagian proses pemanasan dan penuangan ditulis sebagai informasi pembelajaran.
Tahap yang melibatkan bahan panas wajib ditangani orang dewasa dengan pengawasan.
